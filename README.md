# Tempo — персональный Telegram-ассистент дня

Бот помогает держать расписание, сон, вес и мотивацию. Стек: **Python · aiogram 3 · PostgreSQL · Docker**.

## Возможности

- Почасовые пуши «статус дня + текущий блок» (06:30–22:00), суббота — Recovery day без пушей
- Режимы **учебное время / каникулы** (университет пн–пт только в учёбе)
- Сон: кнопки «лёг спать» / «проснулся», AI-план восстановления
- Вес: пятница 20:00, цель 80–85 кг, inline-клавиатура
- Графики Apple-style (сон / вес / продуктивность)
- AI Gemini: режимы «коуч» и «свободный», ротация 3 ключей
- Утренняя мотивация 06:30 (Pinterest → Unsplash fallback)
- Отсчёт до Нового года в меню
- Доступ только для `ADMIN_ID`, остальным — заглушка

## Быстрый старт

1. Заполни `.env` (есть пример в `.env.example`):

```env
BOT_TOKEN=...
ADMIN_ID=5007535736
OPENAI_API_KEY=AQ....,AQ....,AQ....
```

2. Запуск:

```bash
docker compose up -d --build
```

Логи:

```bash
docker compose logs -f bot
```

Локально без Docker (нужен PostgreSQL на `localhost:5433`):

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
# DATABASE_URL=postgresql+asyncpg://tempo:tempo@localhost:5433/tempo
python -m app.main
```

## Меню (inline)

Сейчас · Расписание · Сон · Вес · Статистика · AI-чат · До НГ · Настройки

## Расписание

| Дни | 16:30–20:30 | 07:30–14:00 |
| --- | --- | --- |
| Пн / Ср / Пт | зал + IT | университет (учёба) / самообучение (каникулы) |
| Вт / Чт | IT | то же |
| Вс | IT | самообучение / IT |
| Сб | Recovery day | — |

## Заметки

- Ключи Gemini лежат в `OPENAI_API_KEY` через запятую (как в исходном `.env`).
- Pinterest может блокировать парсинг — тогда подтягивается Unsplash / только текст.
- Порт Postgres на хосте: **5433** (чтобы не конфликтовать с другими ботами).
